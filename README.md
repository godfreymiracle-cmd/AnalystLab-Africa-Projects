# AnalystLab Africa Projects

Projects from the **AnalystLab Africa Experience Lab Internship Programme**, completed as a Junior Data Analyst.

Each week's work sits in its own folder with its own README that explains the problem, the method, the assumptions and the findings.

## Projects

| Week | Project | Tools | Folder |
|---|---|---|---|
| 1 | **ShopSmart Retail Sales Analysis**: cleaned nine retail tables, analysed 50,000 orders (₦7.58B revenue) and built an interactive executive dashboard | Microsoft Excel (Excel Tables, XLOOKUP, pivot tables, pivot charts, slicers) | [Week1_Godfrey_Miracle](Week1_Godfrey_Miracle/) |
| 2 | **Global Superstore Sales & Profitability Dashboard**: cleaned 51,290 order lines and built a four-page Power BI dashboard with insights and recommendations | Microsoft Power BI (Power Query, DAX, slicers, page navigation) | [Week2_Godfrey_Miracle](Week2_Godfrey_Miracle/) |

More weeks will be added as the internship continues.

## Skills shown

- Data cleaning and data quality checks
- Lookup formulas and combining related tables
- Pivot tables and pivot charts
- Interactive dashboard design with KPI cards and slicers
- Power Query data preparation and DAX measures
- Multi-page Power BI dashboards with navigation
- Turning findings into business recommendations
